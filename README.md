#Enhanced CSI Estimation in UV MIMO Systems using Deep Learning Based models

Channel Estimation is the process of estimating channel coefficients between the Transmitter and Receiver.The estimated coefficients are complex valued which are stored in a matrix called the Channel State Information(CSI) matrix.We are proposing a DL based model which helps in estimating a more accurate CSI matrix

Traditional Methods like LS estimation and MMSE Estimation are very unreliable and not accurate enough and require lots of computational resources.
We are proposing two models namely : 
1. CNN+ AM
2. CNN + AM + Transformer

These ensure that the estimated values are much reliable and accurate.
